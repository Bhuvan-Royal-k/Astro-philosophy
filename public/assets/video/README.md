# Video Asset Directory

Place your cinematic temple journey video file here:
- **Expected Path**: `/assets/video/temple-journey.mp4` (or relative path in project: `public/assets/video/temple-journey.mp4`)
- **Recommended format**: H.264 MP4, 1080p or 4K, 30fps or 60fps, optimized for web streaming (faststart / moov atom at beginning of file).
- **Cinematic sequence**: Depicts a sacred journey moving from the cosmic exterior toward the ancient Dravidian temple interior.

If this file is absent, Astro Philosophy automatically engages an elegant procedural cosmic celestial canvas fallback with sacred yantra geometry and golden starlight particles so the website remains stunning and fully functional during development.
