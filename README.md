# Astro Philosophy
### A Cinematic 3D Scroll-Driven Website

**Live Website:** [https://astrophilosophy.vercel.app/](https://astrophilosophy.vercel.app/)

Astro Philosophy is a premium astrology and spiritual services website created for a client. It combines cinematic scrolling visuals, elegant typography, traditional spiritual imagery, and a refined dark-and-gold design to create an immersive digital experience.

## Overview
The website is designed around a scroll-driven cinematic hero experience, where visitors progress through a sequence of visual frames as they scroll. The experience is complemented by service offerings, an introduction to the philosophy, animated statistics, multilingual content, and direct WhatsApp inquiries.

## Features
- **Cinematic scroll experience** — scroll-controlled frame animation with separate desktop and mobile sequences.
- **Premium visual identity** — midnight-indigo backgrounds, antique-gold accents, and elegant typography.
- **Responsive design** — layouts and visual assets tailored to desktop and mobile screens.
- **Spiritual service catalogue** — 13 offerings with dedicated imagery and category filters.
- **Animated statistics** — count-up counters triggered when the statistics section enters the viewport.
- **Multilingual interface** — English, Tamil, Kannada, Telugu, Malayalam, and Hindi.
- **Direct WhatsApp inquiries** — service-specific messages and contact actions.
- **Contact and directions** — business contact information and Google Maps directions using the business address.
- **Optimized visual assets** — compressed service images and dedicated cinematic frame sequences.

## Technology Stack
- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **GSAP and ScrollTrigger**
- **HTML Canvas for cinematic frame rendering**
- **Vercel for deployment**

## Cinematic Animation
The hero experience uses sequential image frames synchronized with scroll progress.
- **Desktop:** 240 landscape frames.
- **Mobile:** 300 portrait frames.
- Canvas-based rendering with responsive scaling and image-loading optimizations.

## Project Purpose
This project demonstrates how a traditional astrology and spiritual services business can be presented through a modern, cinematic web experience. The focus is on visual storytelling, responsive design, accessibility, and clear paths for visitors to explore services and make inquiries.
